## Relecture

Relectures indépendantes du pilote : **sécurité OK, réseau OK, aucun bloquant**. Points appliqués dans un commit de
relecture (versions gardées : rien n'est publié) :

1. **Sécurité, IMPORTANT — motifs `files`** (`tests/spec/ui_shared_spec.lua`) : le test ne cherchait que la chaîne
   `web/dev` ; un `web/**` ou un `web/*/x.js` aurait livré `web/dev/devmock.js` sans le faire échouer. Désormais les
   motifs sont relus dans le manifeste (blocs `files { … }` et lignes `file '…'`, commentaires Lua retirés) : refus de
   `**`, d'un joker dans une partie de dossier et de tout motif sous `web/dev/`, pour `vava_ui` comme pour chaque page
   basculée ; pour `vava_ui`, la liste doit être **exactement** ses quatre motifs.
2. **Sécurité, IMPORTANT** : `vava_ui` ne doit déclarer ni `ui_page` ni `loadscreen` (en plus d'aucun script).
3. **Sécurité, IMPORTANT** : `grain.webp` et `paper.webp` ajoutés aux copies communes interdites dans un module.
4. **Réseau, mineur** : chiffres du dépôt (LF) publiés à côté de ceux de la copie Windows (§ Poids livré).
5. **Réseau, mineur** : README de `vava_ui` : retouches rares et groupées (toute retouche fait retélécharger la
   ressource à tous les joueurs), et règle des motifs `files`.
6. **Réseau, mineur** : `.gitattributes` : `*.webp binary`, à côté de `*.png` et `*.woff2`.
7. Réseau : `body.dev` (aperçu hors jeu) reste dans `style.css` du HUD, négligeable.
