## Autocontrôle sécurité et réseau

- Le serveur décide : la place de retour est lue sur le ped côté serveur au moment où l'observation est accordée
  (droit `spectate` revérifié) ; le client ne fournit aucune position. `spectateEnd` ne peut qu'effacer la place de
  son propre personnage : sans observation, rien n'est écrit ; spam borné par le débit.
- Identifiants : ne partent plus vers aucun jeu ; la Chancellerie garde les siens (acteur créé par `web.lua` seulement
  pour la ressource-pont).
- Noms : les règles envoyées sont des valeurs de config non sensibles ; le serveur revérifie à la création (rien n'est
  cru du client). Le rappel et les séparateurs sont insérés par `textContent`.
- Codex : la normalisation ne donne aucun pouvoir (la commande garde ses contrôles) ; elle évite seulement de lancer
  une valeur que personne n'a choisie.
- Réseau : voir le tableau ; coût ponctuel et ciblé, aucune boucle, aucun envoi à tous.

## Points délicats à faire relire

1. **Retour d'observation** : double apparition au retour (le core fait apparaître le membre là où il a été relevé,
   puis le module le replace) ; l'écran se rallume brièvement entre les deux fondus. Une place peut rester gardée si
   la fin n'arrive jamais au serveur : le membre serait alors ramené à sa place de départ à sa prochaine arrivée, sans
   danger mais inattendu. Une place « parti » restée pendant que `vava_admin` était arrêté est appliquée à son
   redémarrage, même si le membre joue déjà.
2. **Immobilisés libérés à l'arrêt** : un `restart vava_admin` relâche un joueur que le Conseil retenait. Choix
   assumé (voir plus haut) ; T-006 (M2, fin du Gel) touchera peut-être aussi l'état « immobilisé » : à fusionner avec
   attention (`players.frozen`, `actions.freeze`).
3. **Scène de création** : coordonnées vanilla de mémoire (piste de McKenzie), jamais vues en jeu ; si le sol ou le
   cadrage est faux, seule `scene` change.
4. **Version du core** : 0.8.0 (voir Versions).
5. La logique pure côté interface (`normalizeNumber`, `validName`) n'a pas de test versionné : le dépôt n'a pas
   d'outillage de test JavaScript ; elle a été vérifiée sous jsdom hors dépôt.
