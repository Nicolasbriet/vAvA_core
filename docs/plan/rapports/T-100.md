# T-100 — Ressource `vava_atelier` : cadre, accueil, droits

Spec : `docs/plan/specs/T-100.md` (onze décisions retenues sur délégation du porteur du projet ; bouton du Registre
reporté). Procédure en jeu : `docs/tests/atelier.md`.

## Ce qui change

| Partie | Version | Changement |
|---|---|---|
| `vava_atelier` (nouveau) | 1.0.0 | Une page pour tous les ateliers (accueil d'après la maquette `Main` : familles, recherche, brouillons, journal ; liste d'un atelier ; fiche en mise en page `page` ou en volet `side` ; journal entier ; confirmation ; bandeau et barre des touches prêts pour T-102). Registre `vava_atelier:editors` : un module déclare ses ateliers (famille, textes, droit, types, formulaires, fonctions `index`, `read`, `validate`, `options`, `compare`) et reste seul juge de la validité ; une clé hors du préfixe de la ressource déclarante est retirée. Formulaire générique piloté par schéma, huit widgets (`slider`, `segmented`, `select`, `toggle`, `text`, `duration`, `item`, `model`), une phrase d'aide toujours visible. Neuf RPC bornés ; à chaque appel : personnage, `vava_admin` prêt, droit d'ouvrir, session du même compte, droit effectif de l'atelier (plancher `metiers` pour le monde, `staff` pour la société et les arts). « Vérifier » : forme, contrôles du monde, puis `validate` du module ; rien n'est enregistré avant T-101. Journal propre (`vava_atelier_journal`, 365 jours), recopié au Registre. `F9` et `/atelier`. |
| `vava_example_atelier` (nouveau, développement seulement) | 1.0.0 | Deux ateliers (panneaux, droit `metiers` ; proclamations, droit `staff`) qui prouvent le formulaire générique sans code d'interface. |

Réseau : aucun envoi à tous ; deux évènements ciblés (`revoked`, `editorGone`, ≤ 60 o) ; réponses paginées, accueil et
descripteurs renvoyés seulement s'ils ont changé (empreinte) ; aucune boucle client. Page livrée : 98 909 o (polices et
ornements pris dans `vava_ui`).

## Relecture réseau (vava-reseau-perf, 30/10) : À CORRIGER (un IMPORTANT), corrigé ou tranché

## Relecture lore (vava-gardien-lore, 30/10) : À CORRIGER, corrigé

ce que voit le Conseil (« interface », « par défaut », « personnage chargé »…), « besace du royaume » remplacée, champ

## Trouvé en route

`%c` dépend de la locale du système (sous Windows, il prend 0x81, 0x8D, 0x8F, 0x90, 0x9D, 0xAD et refuse « Í », « Ý »,
« í »…) : remplacé dans l'Atelier par `[\0-\31\127]`. Le même motif existe dans le core (`shared/lib/string.lua`),
`vava_chat`, `vava_magic` et `vava_voice` : tâche de backlog.
